# Narration audio

Put one MP3 per page here, named exactly:

p01.mp3  p02.mp3  p03.mp3  …  p12.mp3

Optional language versions (used automatically by the language button):

- p01_zh.mp3 plays in 中文 mode
- p01_en.mp3 plays in English mode
- p01.mp3 plays in bilingual mode, and as the fallback

Pages without a file show "Narration coming soon 旁白即將上線".
Tip: export as MP3, 96–128 kbps mono, so each file stays under about 1 MB.
